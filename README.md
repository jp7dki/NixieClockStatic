# NixieClockStatic

Raspberry Pi Pico (RP2040) を使った、6桁ニキシー管時計のファームウェアと回路図です。
ニキシー管はダイナミック点灯ではなく、シフトレジスタによる**スタティック点灯**で駆動します。
GPS モジュールから受信した時刻で RTC を自動補正し、日本標準時 (JST) で時刻を表示します。


## 主な機能

- **6桁ニキシー管による時刻表示**（時・分・秒）。各桁の左右ドット（小数点）表示にも対応
- **GPS による時刻自動補正**
  - UART1 (9600bps) で GPS モジュールの `$GPRMC` センテンスを受信
  - 測位有効 (`A`) のとき UTC → JST (+9時間) に変換して RTC に設定
  - 毎正時に再度時刻合わせを実施
- **明るさ制御**
  - 光センサ (ADC) の値に応じて PWM デューティを自動調整
  - 桁ごと・数字ごとの明るさ補正値（ニキシー管の個体差・数字ごとの輝度差の補正）
  - 桁ごとの明るさ微調整値をユーザー設定可能
- **1/f ゆらぎ点灯**：ピンクノイズフィルタで明るさに 1/f ゆらぎを付与（振幅は設定可能）
- **数字の切り替え演出**（4種類から選択）
- **毎正時のデモ演出**（ランダムな数字が流れた後に時刻を表示）
- **自動消灯／点灯**：指定時刻に消灯し、指定時刻に再点灯
- **設定値の不揮発保存**：内蔵 Flash (オフセット 512KB) に設定を保存
- **デュアルコア動作**：Core0 で制御・入力処理、Core1 でニキシー管の表示更新を担当

### ピン割り当て (`firmware/nixiev.h`)

| 機能 | GPIO |

| 桁ごとの PWM (明るさ制御) | 0, 2, 4, 6, 8, 10 |
| ドット出力 K3〜K6 (R/L) | 3, 1, 5, 7, 9, 11, 14, 15 |
| デバッグ UART0 TX / RX (115200bps) | 12 / 13 |
| スイッチ SWA / SWB / SWC | 16 / 22 / 23 |
| BME280 (SPI) CSB / SCK / SDI / SDO | 17 / 18 / 19 / 20 |

- BME280（温湿度・気圧センサ）の初期化・読み出し処理は実装されていますが、現状のファームウェアでは表示には使用していません。

## ビルド方法

[Raspberry Pi Pico SDK](https://github.com/raspberrypi/pico-sdk) と ARM GCC ツールチェーン (`arm-none-eabi-gcc`)、CMake (3.13 以上) が必要です。

```bash
export PICO_SDK_PATH=/path/to/pico-sdk
```

```bash
cd firmware
mkdir -p build && cd build
cmake ..
make
```

ビルドが完了すると `build/nixiev_firmware.uf2` が生成されます。
バイナリは `copy_to_ram` 形式で、起動時に RAM へコピーされて実行されます。

## 書き込み方法

1. Pico の BOOTSEL ボタンを押しながら USB 接続する
2. マスストレージとして認識された `RPI-RP2` ドライブに `nixiev_firmware.uf2` をコピーする

SWD デバッガ (OpenOCD + cortex-debug) を使う場合は `firmware/.vscode/launch.json` を参照してください（`localhost:3333` の OpenOCD に接続する設定です）。

## 操作方法

3つのスイッチ (SWA / SWB / SWC) で操作します。

- **短押し**：約 0.1 秒以上
- **長押し**：約 1.5 秒以上

### 起動時

電源投入時に全桁 0〜9 を順に点灯（陰極被毒防止を兼ねたデモ）し、ランダム表示の後にファームウェアバージョンを表示してから時計モードに移行します。

### 動作モードと操作一覧

| モード | 操作 | 動作 |
| --- | --- | --- |
| **時計 (CLOCK)** | SWA 長押し | 設定モードへ |
| | SWB 長押し | ランダムモードへ |
| | SWC 長押し | 明るさ調整モードへ |
| **設定 (SETUP)** | SWA 短押し / SWC 短押し | カーソル（点滅桁）を左 / 右へ移動 |
| | SWB 短押し | カーソル桁の値を変更 |
| | SWA 長押し | 設定を Flash に保存して時計モードへ |
| **ランダム (RANDOM)** | SWA 短押し | ランダムな数字のシャッフル演出 |
| | SWB 長押し | デモモードへ |
| | SWA 長押し | 時計モードへ |
| **デモ (DEMO)** | — | シャッフル演出を繰り返し表示 |
| | SWA 長押し | 時計モードへ |
| **明るさ調整 (LIGHT_ADJ)** | SWA 短押し | カーソル（調整する桁）を移動 |
| | SWB 短押し / SWC 短押し | カーソル桁の明るさを +10 / −10 |
| | SWB 長押し | 表示する数字を切り替え (0〜9) |
| | SWC 長押し | 消灯時刻設定モードへ |
| | SWA 長押し | 設定を保存して時計モードへ |
| **消灯時刻設定 (SLEEP_TIME)** | SWA / SWB / SWC 短押し | 時 / 分 / 秒 を +1 |
| | SWC 長押し | 点灯時刻設定モードへ |
| | SWA 長押し | 設定を保存して時計モードへ |
| **点灯時刻設定 (WAKE_TIME)** | SWA / SWB / SWC 短押し | 時 / 分 / 秒 を +1 |
| | SWC 長押し | 明るさ調整モードへ |
| | SWA 長押し | 設定を保存して時計モードへ |

### 設定モードの表示内容

設定モードでは6桁に以下の項目が表示されます。

| 桁 | 項目 | 値 |
| --- | --- | --- |
| 1桁目 | 数字の切り替え演出 | `0`: 通常切り替え / `1`: クラウド（数字が流れて切り替わる） / `2`: パタパタ（変化した桁のドットを一時点灯） / `3`: ドットムーブ（ドットが桁間を移動） |
| 2桁目 | 毎正時のデモ演出 | `0`: OFF / `1`: ON |
| 3桁目 | 自動消灯 | `0`: OFF / `1`: ON |
| 4〜6桁目 | 1/f ゆらぎの振幅 | `000`〜`999`（各桁ごとに変更） |

### 初期設定値

Flash が未初期化の場合、以下の値で初期化されます。

| 項目 | 初期値 |
| --- | --- |
| 切り替え演出 | 1（クラウド） |
| 毎正時のデモ | ON |
| 自動消灯 | ON |
| 消灯時刻 | 22:00:00 |
| 点灯時刻 | 06:00:00 |
| 1/f ゆらぎの振幅 | 0 |
| 桁ごとの明るさ調整値 | すべて 0 |

## ソフトウェア構成

| 処理 | 内容 |
| --- | --- |
| `main()` (Core0) | 動作モードのステートマシン、スイッチ入力、各種アニメーション、GPS 時刻合わせ |
| `core1_entry()` (Core1) | マルチコア FIFO の通知を受けてニキシー管表示 (`disp_num`) を更新 |
| `timer_alarm0_irq` (1秒周期) | 時刻表示の更新、消灯／点灯時刻の判定 |
| `timer_alerm1_irq` (40ms周期) | 光センサ読み取り・1/fゆらぎを反映した PWM 更新、切り替え演出、設定時のカーソル点滅 |
| `alarm_callback` (RTC アラーム) | 毎正時の GPS 再補正フラグ・デモ演出フラグの設定 |
| `disp_num()` | 表示データを 64bit のシリアルデータに変換してシフトレジスタへ送信し、ドット出力を制御 |

### 表示データ (`disp[]`) の形式

`disp[0]`〜`disp[5]` が左から各桁に対応します。

- 下位4bit：表示する数字 (`0`〜`9`)、`10` で消灯
- 上位4bit：ドット表示 (`0x1`: 右, `0x2`: 左, `0x3`: 両方)

## 注意事項

- ニキシー管の駆動には高電圧 (HV) を使用します。製作・取り扱いの際は感電に十分注意してください。
- タイムゾーンは JST (UTC+9) 固定です。
